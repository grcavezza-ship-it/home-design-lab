# Atelier Botanical - Project Structure for Cursor ## Project Overview This folder contains the complete high-fidelity design for the "Atelier Botanical" website, a luxury architectural and real estate platform. ## File Structure - `index.html` (Homepage - Focus Progettazione) - `chi-siamo.html` (About Us) - `servizi-lab.html` (Technical Services) - `collection.html` (Real Estate Gallery) - `dettaglio-immobile.html` (Villa Orizzonte Detail) - `portfolio.html` (Completed Projects) - `dettaglio-progetto.html` (Attico Prisma Case History) - `journal.html` (Blog/Insights) - `contatti.html` (Contact Forms) - `login.html` (Client Area Login) - `dashboard.html` (Client Project Dashboard) - `404.html` (Error Page) ## Technical Specifications - **Framework:** Tailwind CSS (CDN included in files) - **Typography:** Noto Serif (Titles), Manrope (Body) - Google Fonts - **Color Palette:** - Deep Green: `#186C32` - Fresh Green: `#4CAF50` - Warm Sand Beige: `#D4BFA7` - Dark Charcoal: `#333333` - Pure White: `#FFFFFF` ## How to use in Cursor 1. Create a new folder in your local machine. 2. Open the folder in Cursor. 3. Use the code from the 'View Code' button for each screen to create the corresponding `.html` files listed above. 4. You can ask Cursor to 'refactor these files into a React/Next.js project' or 'optimize the CSS' once the basic structure is in place.
